Project Overview

This project uses Machine Learning classification algorithms to predict
whether a credit card customer is likely to default on their next
month's payment.

The project is based on a credit card dataset containing customer
demographic information, credit limit, repayment status, bill amounts,
payment amounts, and the target variable indicating payment default.

Objective

The main objectives of this project are:

Analyze the credit card customer dataset.

Perform data preprocessing and cleaning.

Handle outliers.

Encode categorical variables.

Balance the target classes using SMOTE.

Select relevant features.

Transform and scale the data.

Train multiple Machine Learning classification models.

Evaluate and compare model performance using accuracy, precision,
recall, and F1-score.

Identify the best-performing classification algorithm.
